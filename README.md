# Lotus Colour Automation

Dépôt officiel NALINFORGE pour l’App Home Assistant **Lotus Colour Automation**.

Version distribuée : **0.2.13 — bêta**

## Installation dans Home Assistant

Une fois ce dépôt rendu public :

1. Ouvrir **Paramètres → Apps**.
2. Ouvrir l’App Store.
3. Ouvrir **Dépôts**.
4. Ajouter :
   `https://github.com/NALINFORGE/LotusColourAutomation`
5. Installer **Lotus Colour Automation**.

L’App est stockée dans le dossier technique `lotus_automation_monitor` afin de conserver son identifiant historique.

## Fonction

Lotus Colour Automation ajoute un suivi visuel en temps réel aux interfaces natives Home Assistant des automatisations et scripts : exécution en cours, erreur, progression des actions, heures de début/fin et durée d’exécution.

## Compatibilité

Les identifiants techniques historiques restent inchangés :

- slug : `lotus_automation_monitor`
- domaine Home Assistant : `lotus_automation_monitor`
- URL frontend : `/lotus_automation_monitor/...`
